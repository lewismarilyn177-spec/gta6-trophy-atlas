An interactive offline trophy guide and tracker for all 55 GTA 6 PlayStation 5 trophies. Browse official trophy names, descriptions, and grades; follow step-by-step guides with source citations; plan your platinum roadmap across stages; filter by story, missable, collectibles, or activities; toggle spoilers; and save progress locally with export/import.

## Run it

```sh
node serve.ts   # opens http://localhost:8080
```
