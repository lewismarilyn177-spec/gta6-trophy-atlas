An interactive offline trophy guide and tracker for all 55 GTA 6 PlayStation 5 trophies. Features a complete roadmap with missable flags, advanced filters for trophy type and difficulty, a spoiler toggle to hide story-related details, and local save persistence so your progress survives browser restarts — no account or internet required.

## Run it

```bash
node serve.ts
```
