An offline guide and tracker for all 55 GTA 6 PlayStation 5 trophies: official names, descriptions and grades, a per-trophy guide citing its sources, a roadmap to the platinum in stages, every missable flagged, story/missable/collectibles/activities filters, a spoiler setting, and localStorage progress with export/import.

## Run it

```sh
node serve.ts   # opens http://localhost:8080
```
